## Requirements
### Requirement: Generic agent instruction file generation
`patina install-agent` SHALL behave as a deprecated compatibility alias for `patina install-skills`. It SHALL accept the same effective options needed to preserve current usage where possible, route to the install-skills implementation, and emit a deprecation warning telling users to use `patina install-skills`.

#### Scenario: Install-agent writes shared instructions through install-skills
- **WHEN** `patina install-agent` is run and `<knowledge_dir>/AGENTS.md` does not exist
- **THEN** `<knowledge_dir>/AGENTS.md` is created with the Patina shared operating instructions generated by `install-skills`
- **AND** a deprecation warning is emitted

#### Scenario: Install-agent force delegates to install-skills
- **WHEN** `patina install-agent --force` is run
- **THEN** Patina applies the same write policy as `patina install-skills --force`
- **AND** a deprecation warning is emitted

### Requirement: Agent instructions are thin CLI wrappers
Generated Patina agent instructions and skills SHALL describe how to use local Patina CLI commands such as `patina query`, `patina read`, `patina lint`, `patina stale`, and `patina index`. Generated files SHALL NOT define host-specific protocols as the primary integration mechanism, and SHALL NOT pre-approve shell execution through `allowed-tools` by default.

#### Scenario: Generated instructions reference CLI commands
- **WHEN** `patina install-agent` creates or updates Patina-managed instructions through the install-skills implementation
- **THEN** the generated content references Patina CLI commands including `patina query`, `patina read`, and `patina lint`

### Requirement: Tool-specific instruction target
`patina install-agent --agent <name>` SHALL be superseded by `patina install-skills --for <target>`. If the alias preserves `--agent` compatibility, recognized old agent names SHALL map to the corresponding install-skills target and emit a deprecation warning. Unknown agent values SHALL emit an error listing supported install-skills targets.

#### Scenario: Known old agent target maps to skill target
- **WHEN** `patina install-agent --agent claude-code` is run
- **THEN** Patina behaves like `patina install-skills --for claude-code`
- **AND** a deprecation warning is emitted

#### Scenario: Unknown old agent target errors
- **WHEN** `patina install-agent --agent unknown-tool` is run
- **THEN** an error is emitted listing supported install-skills targets

### Requirement: Install-agent JSON output
`patina install-agent --json` SHALL return the standard JSON envelope produced by the install-skills implementation, with command identity and warnings making the deprecation clear.

#### Scenario: Install-agent JSON reports deprecation and written files
- **WHEN** `patina install-agent --json` succeeds
- **THEN** `ok` is `true`
- **AND** `data.files_written` is an array of paths created or modified
- **AND** `warnings` contains a deprecation warning for `install-agent`
